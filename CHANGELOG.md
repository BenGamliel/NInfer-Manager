# Changelog

## 1.0.0

- Modern lightweight WinForms application and notification-area controls.
- Clean no-model first run with a skippable Setup Wizard.
- Automatic free-port recovery, exact-port locking, and temporary or saved port changes.
- On-demand OpenAI-compatible proxy and automatic VRAM unload.
- Per-model profiles covering practical `ninfer-serve` options.
- Official five-model embedded catalog and upstream model-card discovery.
- Resumable model downloads, SHA-256 verification, import and recoverable delete.
- Portable and per-user Installer packages without bundled model artifacts.
- Automatic update offers, manual checks, and verified Installer/Portable update flows.
- Redacted diagnostics, bounded logs, documentation and repository audit tooling.
